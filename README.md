## Usage

1. Download and extract the repository files.
2. Open the `/docs` folder and read the `GettingStarted.md` guide.
3. Choose your desired configuration:
   - **Templates:** Import the project and title templates from `/templates` via Vegas Pro's File > Open or Project Templates.
   - **Scripts:** Run the automation scripts from `/scripts` using Vegas Pro's scripting or macro tools.
   - **Presets:** Apply the color grading, AI, and export presets from `/presets`.
4. Launch Vegas Pro and follow the documentation to apply your configurations.
